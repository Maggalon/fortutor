# For Tutor

SaaS для частных репетиторов: 14 дней бесплатно без карты, затем 1190 ₽ за календарный месяц через ЮKassa. Кабинеты преподавателя и ученика с Telegram/MAX, учетом оплат занятий и отчетами DeepSeek. Интерфейс на русском, адаптивный, со светлой и темной темами. Родитель взаимодействует через бота.

## Быстрый запуск

Требуются Node.js 24 и pnpm 12.4.2. Команды выполняются из корня проекта:

```sh
npm install -g pnpm@12.4.2
pnpm install --frozen-lockfile
pnpm dev
```

Откройте [localhost:3000](http://localhost:3000). Без `DATABASE_URL` в development доступна демонстрация с локальным сохранением в `.data/`. Кнопки входа показывают кабинеты преподавателя и ученика. Изменения сохраняются после перезапуска. Демонстрация **не отправляет настоящие уведомления**; production запрещает этот режим.

Для полноценного локального окружения и настоящих интеграций следуйте [инструкции разработки](docs/DEVELOPMENT.md).

## Реализовано

- Регистрация преподавателя, одноразовые приглашения ученика на 7 дней, роли и изоляция данных преподавателей. Пароли scrypt, сессии с HttpOnly cookie, защита запросов по Origin и ограничение попыток входа.
- Ученики, группы, одноразовые коды родителя с перевыпуском. Подключение Telegram и MAX из кабинета ученика; отключение привязок.
- Недельный календарь и список занятий, разовые и еженедельные серии до 52 недель, проверка пересечений, перенос/отмена/проведение, посещаемость, сохранение локального времени при переходе на летнее время.
- ДЗ с текстом, ссылками, JPG/PNG/PDF до 20 МБ и дедлайном. Назначение группе или отдельным ученикам; отправка через веб и оба бота, подтверждение, баллы, комментарии, доработка, архив.
- Поурочный долг и пакеты занятий. Ручная фиксация платежа, закрытие конкретных проведенных уроков, сохранение цены на момент проведения, защита от двойного списания и повторного закрытия долга. Пропущенное учеником занятие не списывается.
- Уведомления о новом ДЗ, проверке и сроках; напоминания об уроке за 24 и 2 часа; родительские уведомления об оплате с реквизитами. Независимые провайдеры Telegram и MAX.
- Отчеты по выбранному периоду и автоматически каждые 14 или 30 дней. Реальный вызов DeepSeek, контекст из посещаемости/проверенных работ, сохранение текста и доставка родителям. Согласия собираются вне платформы; их наличие не проверяется приложением.
- PostgreSQL, долговечный outbox, Redis/BullMQ worker, повторные попытки и ручной перезапуск неудачных задач. Прямая загрузка в приватный S3 с проверкой размера, сигнатуры и прав доступа.
- Подписка: 14 дней пробного доступа, 1190 ₽/месяц, явное согласие на автопродление, история оплат и отключение автопродления. Проверка платежей через API ЮKassa, повторные проверки worker, защита от двойного продления. После истечения — просмотр/экспорт; у платного автопродления 3 дня льготного доступа.
- Запросы авторизованного кабинета и подписки читают данные только своего преподавателя и используют отдельную блокировку tenant. Фоновое планирование также выполняется по tenant.
- VPS за существующим Nginx Proxy Manager. GitHub Actions собирает готовые Docker-образы web/worker до отправки на сервер; передача по SSH, миграция, backup перед обновлением, запуск без сборки на VPS.

## Проверки

```sh
pnpm typecheck
pnpm test
pnpm build
```

Автоматические тесты проверяют бизнес-правила, подписки и интеграционные сценарии, включая первый deployment без ЮKassa. Для запуска всех задайте `TEST_DATABASE_URL` и `TEST_REDIS_URL`: без них тесты PostgreSQL/Redis пропускаются. В CI поднимаются оба сервиса. Внешние API, включая ЮKassa, и S3 в автоматических тестах имитируются на границе транспорта; работа с настоящими ключами проверяется по [чек-листу приемки](docs/ACCEPTANCE.md).

Для запуска потребуются GitHub-репозиторий, домен, VPS с Docker/Nginx Proxy Manager и ключи S3. Магазин ЮKassa можно подключить после deployment и проверки сайта: оставьте оба ключа магазина пустыми, регистрация и 14-дневный trial работают без платежей. Порядок подключения без пересборки образов описан в [BILLING.md](docs/BILLING.md#первый-запуск-без-юkassa). Production-шаблон — `deploy/env.production.example`. CI/CD начинает работать после публикации репозитория и настройки SSH secrets/variables. Секреты сохраняются только на сервере. Файлы Manrope перенесены из `meta-platform`; условия распространения находятся в `public/fonts/OFL.txt`.
